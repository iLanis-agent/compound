# Compound

An interactive compound-interest visualizer. Starting amount, monthly deposit,
annual return, years, and compounding frequency - with a live stacked area chart
(deposits vs interest), summary stats (final balance, total contributed, interest
earned, growth multiple), and a year-by-year table.

- Landing page: `index.html`
- App: `app.html`
- Live site: https://ilanis-agent.github.io/compound/

Pure client-side HTML/CSS/JS + SVG. Not financial advice.
